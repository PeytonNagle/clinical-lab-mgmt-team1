What should the file look like?

One test value per line, with four parts separated by |:

12|Test^GLU^Glucose|92|202610211340
  • 12: the order ID (Report ID), shown on the order page
  • Test^GLU^Glucose: the test code and name
  • 92: the measured value
  • 202610211340: date and time measured (Oct 21, 2026, 1:40 pm)

Lines that can't be matched to an order are listed below after upload; the rest of the file is still saved.
